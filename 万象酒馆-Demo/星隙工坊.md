# 星隙工坊

星隙工坊入口位于游戏右上角，靠近「设置」。等待生成或模型列表时也可从等待条进入。接口返回后可以返回查看或继续经营。

## 玩法

沿用原版洞府的画面布局和已登记节点位置。金币、以太和炉心在上方，生产、研修和物资簿在底部。中央画布左侧可以归位和缩放。点图标开始制作、建造或研修，点名称或右键打开详情。

- 从星尘、净泉、麦粒三种原料开始，手作解锁后续物资。手作开始时支付原料，每种物资可同时进行一项手作，完成一次后停止。
- 交付物资获得金币。建造设施按配置消耗酒馆金币、以太和工坊建材。每种设施可反复建造，通过运转数量滑条调节开工数量，设为0保留当前进度。
- 自动设施支持各产物单独计时，也支持按设施周期投入一批原料并结算多项产物。
- 制成工坊机芯后开启研修。前置设施、研修等级、产线速率与并行数均由统一数据引擎计算。
- 炉心共5级，增加生产速率和手作额外速率。
- 共有43种物资、25类设施、26项研修。完整目录位于 `src/content/workshop-catalog.js`。
- 工坊物资保存在物资簿。进度随游戏存档自动保存，支持存档位和完整备份。关闭工坊后仍计时，重开最多结算8小时离线产出。
- 等待主角生成时积累的工坊进度会带入确认后的新冒险，不会被角色创建重置。

## 修改器

在项目根目录双击「一键启动工坊修改器.cmd」。工具从本机游戏服务读取当前工坊配置，在独立页面中打开。

- 物资和设施共用生产蓝图，研修有独立画布。蓝图为 96×148 像素一格，拖动节点按整格吸附。拖动空白处平移，滚轮缩放，Shift 拖动框选。可以展开画布、移动整组选中节点、横向或纵向排布，以及追踪上下游连线。
- 检查器可编辑建材、前置设施、研修解锁、持有材料、炉心等级、组合条件和永久可见。增建造价、逐级研修费用与效果、炉心奖励和自定义分页也使用表单。图标和色调默认收起。
- 支持新增、复制、删除、撤销重做、草稿、配置预览及 JSON 导入导出。快捷产线可先预览，再生成 1～8 段物资及设施。快捷蓝图还可生成预设设施或批量调整生产周期。
- 保存节点写入浏览器草稿。「应用到游戏」校验后写入本机「存档」目录下的 `工坊配置.json`，并备份上次的自定义配置。下次打开游戏中的星隙工坊时读取新配置。
- 「重读游戏配置」可重新载入当前生效的目录。已被引用的条目须保留稳定 ID。玩家生产进度单独保存在游戏存档中。

## 迁移依据与适配

参考的是《玄天修仙录修改器》实际指向的《玄天修仙录（重置版）》已注册洞府目录，而非未注册备份或旧界面。实际注册数量为43/25/26，修改器注释中的更大数量已经过时。

手作、自动化、数量调节、涨价曲线、依赖显现、研修与核心升级沿用原洞府玩法。原灵石造价适配为金币与以太，原修炼加成适配为手作额外速率。老存档首次打开工坊时，剩余工坊券按一比一转为金币。

源目录中的晶砂分选台需要自身三种产物才能首次建造，而这些产物原本是建成才显现。迁移后将这三种物资改为原料齐备即可显现手作配方，保留费用，消除推进死锁。长离线结算分块执行，未处理时间留在水位中继续结算，不会因帧数预算而丢产量。

`tools/import-workshop-reference.mjs` 是一次性目录迁移工具，不是运行时依赖。它只读取已注册资源，显式处理三处源文件重复字典残片。运行游戏无需安装Godot或保留外部工程。

## 代码与验证

纯数据规则：`src/workshop/engine.js`；目录校验与引用：`src/workshop/catalog.js`；共享蓝图布局：`src/workshop/layout.js`。控制器与视图分别在 `src/app/workshop*.js`，组件样式仅在 `styles/workshop*.css`。API入口统一接入 `src/app/request-controls.js`。

本轮清单位于 `tools/testing/checklist.json`，统一执行 `node tools/test.mjs`。规则测试覆盖完整可达性、手作扣料、自动批次、暂停、离线与帧分割一致性、存档和非法目录；浏览器检查覆盖实际生产、修改器、导入导出、14类等待入口、并发返回、终止和卸载清理。未改变战斗规则，不运行六场副本。
