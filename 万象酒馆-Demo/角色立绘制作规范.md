# 角色立绘：两张原图标准

每个角色制作两张：战斗卡面、透明全身原稿。场景使用完整全身，Gal 使用同一原稿，通过界面裁切显示半身；不再单独生成第三张 Gal 图，避免脸型和服装不一致。保留原始分辨率与 PNG 透明通道，不缩小或重新压缩原图。

## 通用画风

以游戏内正式角色成图为准。采用二维日系幻想绘法，用细而有色的轮廓线，受光边缘让线融进色块。先用清晰的大面明暗塑形，再在脸颊、鼻梁和衣料转折处细柔过渡。眼形自然，虹膜和眼睑清楚。头发按成组的发束画起伏，用细窄高光表现发丝方向。衣料先画大褶，再用少量刺绣、宝石和金属高光点缀。保留通透明快的角色本色，用冷暖分面和轻微反光增加体积。

生成时把参考 PNG 与提示词一起上传。先生成卡面，选定后再做全身。卡面用游戏原卡参考线条、上色和光影，角色的长相与服装以本角色设计图和设定为准。全身图以本角色定稿卡面锁定身份，另附一张游戏全身原稿参考技法和站姿。

- 卡面风格参考任选一张。 [骆公绪](assets/portraits/luo-gongxu-v2.png) · [西莉卡](assets/portraits/silica-laps-v3.png) · [伊蒂丝](assets/portraits/edith.png)
- 全身风格参考任选一张。 [骆公绪全身](assets/tavern-visitors/luo-gongxu-full-v2.png) · [西莉卡全身](assets/tavern-visitors/silica-laps-full-v2.png)

## 提示词一：战斗卡面

```text
生成一张《万象酒馆》角色战斗卡面，1024×1536 竖版 2:3。
随附的游戏原卡只参考线条、上色与光影。本角色的脸型、发型、服装、配色与道具以设计图和设定为准：{角色造型与神情}。
用细彩轮廓和清楚的大面明暗塑形，受光边缘融进色块，脸和布料转折处细柔过渡。成组画发束和细高光，保留通透明快的本色、冷暖层次和克制的材质亮点。避开粗黑描边、棕灰滤镜、仿旧纸纹、密集排线、塑料皮肤、照片写实和 3D 渲染。
画到腰部或上胯，轻微三分之四转身，双肩入画，头顶及发饰留白，脸在画面上三分之一并保持清晰。用方向一致的柔和侧光和环境反光衬托脸部。背景取自角色设定，用低对比的前后景衬出剪影，脸后保持简洁。单张插画，无文字、水印、边框、UI 或拼图。
```

## 提示词二：场景与 Gal 共用全身原稿

```text
生成一张《万象酒馆》场景与 Gal 共用的透明全身立绘，1024×1536 竖版 2:3。
第一张参考是本角色定稿卡面，锁定脸型、五官、发色、服装结构、饰物和配色。第二张是游戏内全身原稿，只参考站姿、全身比例和上色技法。卡面以下未画出的部分按角色设定补足：{服装下半身、鞋和道具}。
延续卡面的细彩轮廓、分层明暗、发束高光和材质细节，用中性柔光保留角色本色。避开粗黑描边、棕灰滤镜、仿旧纸纹、密集排线、塑料皮肤、照片写实和 3D 渲染。
正面自然站立，脸和胸朝向观者，双脚落在同一水平面。完整呈现头发、发饰、手指、衣摆、道具和双鞋底，头顶及脚底各留至少 4% 透明边距。手臂和道具贴近身体，长发、翼和尾收拢在身体附近。
输出 PNG RGBA，轮廓外及发丝、衣摆、双腿之间的空隙均为透明 alpha=0。只保留实体及轮廓抗锯齿。无背景、地面、投影、外发光、文字、水印、边框或 UI。
```

## 通用负面要求

粗黑描边、棕灰滤镜、仿旧纸纹、密集排线、照片写实、3D 渲染、塑料皮肤、强泛光、荧光配色、密集粒子、脸部模糊、畸形手指、裁切头部或鞋底、文字、水印、卡牌边框和 UI。

## 接入与验收

- 完整原稿、实际提示词和来源记录保存在项目中。此次两名角色见 `assets/character-art.json`。
- `content/tavern-visitors.js` 统一登记同一人物的站立源图及头顶、脚底位置；Gal 直接复用该源图。
- 全身按脚底定位并添加程序阴影；Gal 顶部对齐，界面裁掉下半身，不另存一张被缩小的半身图。
- 在卡牌小尺寸、桌面 Gal、手机横屏 Gal 和场景站立四处检查脸部可读性、身体比例、边缘透明、头顶与脚底；图片不能替代场景家具或把人物嵌进墙、楼梯、床铺。
