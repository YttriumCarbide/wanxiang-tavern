# 角色立绘：两张原图标准

每个角色制作两张：战斗卡面、透明全身原稿。场景使用完整全身，Gal 使用同一原稿，通过界面裁切显示半身；不再单独生成第三张 Gal 图，避免脸型和服装不一致。保留原始分辨率与 PNG 透明通道，不缩小或重新压缩原图。

## 通用画风

日式幻想 RPG 卡牌插画，精致二维手绘动漫，复古 JRPG 游戏美术质感。清晰优雅的轮廓线，细腻赛璐璐与轻厚涂结合，柔和而明确的明暗色块，阴影保留手绘笔触。服装剪影有辨识度，细节精致但适度简化，减少密集纹样。精美动漫五官、自然神情，略低饱和的协调配色，少量金属与饰品点缀。

角色配色按自身设定安排；统一绘制技法、阴影和光照，不强制所有角色使用绿色背景。骆公绪用玉绿、象牙白、石青与淡金；西莉卡用深紫、象牙白、粉紫与柔金。

## 提示词一：战斗卡面

```text
【角色】{姓名、性别与成年外观、脸型、发型发色、服装主色、重要饰品、武器、神情}
【画风】使用上面的通用画风，确保脸与上半身清晰，缩小为战斗卡牌仍能辨认。
胸像到腰部构图，角色占主体，自然有辨识度的姿势。头顶、发饰和手臂保留安全边距，武器局部可出现，不让武器遮住脸。简洁低对比幻想背景，使用{角色配色}，柔和环境光，少量暗青与金色反射，禁止繁杂背景和强光效。竖版2:3，不画边框、文字、水印或UI。
```

## 提示词二：场景与 Gal 共用全身原稿

```text
【角色】与卡面同一人物，保留完全一致的脸、发色、服装结构、配色和辨识物。
【画风】使用上面的通用画风。动漫脸部清楚，面部细节优先。
正面自然站立，脸和胸朝向观者，双脚落在同一地面；完整头顶、发饰、手指、衣摆与鞋底，头顶与脚底各留至少4%透明安全边距。武器竖直靠近身体，手臂、头发、尾巴和翅膀保持紧凑，不向两边无限展开。不要战斗冲刺、夸张透视或斜躺姿态。
真正透明alpha背景，轮廓外全部透明，只保留人物和真实服饰、头发、道具；不画地面、背景色、雾、渐变、发光云、外轮廓光晕或投影。场景接触阴影由程序单独添加。竖版2:3，最高原生分辨率。此图同时用于全身站立和Gal半身裁切，不画半身截断版。
```

## 通用负面要求

照片写实、真人摄影、3D 渲染、塑料皮肤、过度磨皮、AI 写真感、超高频碎细节、强 Bloom、霓虹荧光、过饱和、复杂粒子、杂乱背景、过锐化、脸部模糊、低质量像素化、文字、水印、卡牌边框、UI、裁切头部或鞋底、畸形手指。

## 接入与验收

- 完整原稿、实际提示词和来源记录保存在项目中。此次两名角色见 `assets/character-art.json`。
- `content/tavern-visitors.js` 统一登记同一人物的站立源图及头顶、脚底位置；Gal 直接复用该源图。
- 全身按脚底定位并添加程序阴影；Gal 顶部对齐，界面裁掉下半身，不另存一张被缩小的半身图。
- 在卡牌小尺寸、桌面 Gal、手机横屏 Gal 和场景站立四处检查脸部可读性、身体比例、边缘透明、头顶与脚底；图片不能替代场景家具或把人物嵌进墙、楼梯、床铺。
