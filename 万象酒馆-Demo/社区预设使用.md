# 内置提示词预设及世界书

首次开局保存 API 连接后进入主角创建。设置中的 API 连接预设仍可命名和批量应用。提示词页面使用内置的 Meowssiah 2.1.7，可查看作者声明并预览当前用途实际发送的消息及参考 TK。预览共用生成管线，无模型请求或世界书计时推进。

## 玩家选项

文风、篇幅、人物表现和互动偏好只用于叙事正文。成人文风各档、成人 ASMR 和相关原文保存在内置数据中，由玩家设置选择。地图与以太造物遵循各自游戏规则，记忆总结使用专用框架。

原预设的正文外壳统一使用 `<wanxiang_output>`。游戏独立读取好感、任务和约见的结构化附录。开启“使用正文工具”且接口配置选择“合并含工具”时，酒馆交流、快速闲聊和剧本可通过标准工具 `game_content` 传回完整回复，工具参数仍进入相同的格式校验。普通连接读取回复文字。模型的输出行为由其服务端决定。

## 世界书

世界书继续按用途、关键词、蓝绿灯、递归、概率和预算注入。角色、剧本、地图、以太造物的格式条目保持独立。小总结、猫猫留言和原版行动面板已退役，记忆总结和游戏原生行动选项继续按原有流程运行。

旧备份中的正则记录和外部预设记录会在恢复时跳过。原有世界书斜杠正则关键词保持未触发，普通关键词照常匹配。内置预设无需第三方脚本、悬浮窗口或远端日志服务。
