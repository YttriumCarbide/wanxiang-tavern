## 1. 敌人为什么经常挂流血

**这份存档的六名编队成员都装了通用战技「裂甲斩」。** 它本身附加易伤和流血，实际层数会随战斗编译后的成长数值变化。逐个核对了队伍中的 11 件已装备物品，未找到施加流血的词条。将装备从内存副本中卸下，仍能复现，磁盘存档未写入。

| 隔离操作                               | 敌方新增流血 |
| -------------------------------------- | ------------ |
| 六名成员各自上前场，只用普通攻击       | 0 层         |
| 青缘用裂甲斩，当前装备／空装备         | 都是 5 层    |
| 其他五人各自用裂甲斩，当前装备／空装备 | 都是 4 层    |
| 青缘用疾风断脉，空装备                 | 7 层         |

潘多拉戴的玖柒还有一条触发路径。结合期间受到敌方负面状态时，「万法归寂」能返还给施加者，敌人自己施放的流血也在范围内。最近一次保存的战斗记录里没有那一击的施加记录，无法倒查某一帧是哪条路径触发。

流血在中招者**每次行动前**结算，正常回合结束减 1 层。能连续出手的敌人，一回合可能跳血多次。状态图标过去只给层数，战报也容易只剩「行动前流血」。现在新增负面状态的预演提示会列出施加者、技能或触发规则、层数。战报数据也记录实际来源，被挡住的施加不会记成成功。 [通用战技表](src/content/learnable-skills.js) · [结算引擎](src/engine.js) · [纹章规则](src/emblem-mechanics.js) · [预演提示](src/ui.js)

首轮强制教学实际是 **创角 → 酒馆门口与外出 → 控制战斗时间轴 → 学会看意图及换位 → 易伤／迟缓／双敌意图 → 首领和法力药 → 以太结算 → 固定召唤月汐 → 约见 → 买补给、看凝聚器 → 再出发**。现代剧本把中段三项放在精英战，旧五战路径分散到若干战。关闭叙事生成时会跳过桌边和邀请步骤。不同存档进入教学时，能看到的课程受进度和战斗事件影响。

## 3. 完成度与系统衔接

除了公会固定悬赏，酒馆还会从闲聊收集委托传闻。社交委托生成五幕场景和装备奖励，角色委托可以要求队伍等级、酒馆阶数、好感与交涉检定，战斗委托能生成新地图发现并等玩家通关。三类委托共用手记，但正常开局没有走过任意一类从传闻、接取、抵达指定地点到交付的完整链路。若生成角色委托要求酒馆二阶，同样会遇到当前升阶上限。召唤之门另有官设、混沌、无限、已知 NPC 四种来源，各自的角色池在召唤规则中定义。

## 4. 本次修复与验证范围

- 在统一战斗事件里标记负面状态实际来源，预演提示读取同一批事件。装备规则、技能和玖柒返还能分别显示来源。普通攻击不会凭空叠流血。
- 修复公会已购卷宗的地图按钮，修正调阅前的说明。公会和手记现在使用同一套悬赏目标，已接任务的旧存档也会显示新说明。浏览器回归确认卷宗可打开并关闭真实地图对话框。
- 修正首次整备的四槽说明，类别来自装备规则表。修正现代副本节点的代码注释。更新地图数量、装备／纹章恢复、强化普通攻击和纹章教学相关的测试数据。
- 通过定向核心测试、代码质量检查、敌方意图、状态与纹章浏览器回归、纹章教学浏览器回归。本轮以现行规则、测试存档与局部入口为证据。真实 AI 输出差异、所有首领通关和所有手机尺寸未逐一实测。
