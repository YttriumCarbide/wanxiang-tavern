## 对照方法

- 用拆分前的源码和同一批快照对比 8 种战斗情景。逐项比较预演事件、最终状态以及回合推进结果。包含普攻、道具、换位、换入、流血致死、再生与中毒、沉疫和先手。
- 对比装备生成及穿戴、带固定随机种子的营业运行与结账、样例旧档的恢复结果。四个领域原入口导出的接口也逐项比较。
- 回归时修复了账簿的原始返回入口。在当前场景没有专项诊断时，可以打开本页最近一条 API 返回。外出地图断言改为验证现行的无边框羊皮纸绘制。
- 131 项定向核心用例及失败项复查通过。代码质量、日常营业与约见、外出、静态接口设置、磁盘存档、敌方意图、状态与纹章、阿佩普演出均通过。
- 验收运行使用独立测试存档和模拟连接。记录目录为 `.runtime/tests/game-refactor-20261120/`。

DS 直接写了道具与换阵模块，并写了搬移顶层声明的工具。由该工具按语法边界生成的模块经过接口及行为核对。工具实际报告输入 23,779 Token 和输出 6,626 Token。失败日志摘要的两次调用未成功，未返回用量。
