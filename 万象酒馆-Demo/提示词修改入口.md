# 社区预设与游戏规则修改入口

日常操作与兼容范围见[社区预设使用.md](社区预设使用.md)。

| 修改内容       | 入口                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------- |
| 第三方文风预设 | 设置 → 提示词预设；导入、拖拽排序、点铅笔编辑、选择当前API使用                                     |
| 游戏生成要求   | 设置 → 世界书；顶部“角色格式 / 剧本格式”直达输出约束，其余生成要求也在同一本书内                   |
| 发送对象       | 每条世界书的“发送给”：角色、剧本、两者、都不发                                                     |
| 位置与身份     | 条目顶栏；角色定义前后、@D深度、SYSTEM/USER/ASSISTANT等                                            |
| 正则           | 设置 → 正则；选择全局或预设来源，导入并测试                                                        |
| 最终发送及TK   | 预设或世界书的预览按钮；不调用模型                                                                 |
| 代码读取的结构 | 世界书的JSON输出格式 @D条目；模板在prompts/worldbook/_-output.md，动态结构由src/ai/_-schema.js提供 |

默认要求原文位于prompts/worldbook/，只在首次迁移写入本机世界书；之后在编辑器改条目，重启不覆盖。生成诊断可对照原文、正则替换与格式修复，并本地重新校验。

剧本当前采用v3：正文五段自由小说文本，元数据单独放在data。要改项目提醒，编辑世界书“副本剧本 · 自由叙事与伏笔”；要改文风，编辑或切换你导入的预设。v8升级会一次性替换旧的四个项目剧本规则并停用留存原文，之后的编辑仍保留。
