# 控制器状态污染与测试薄弱点清单

审计范围是 `develop` 工作区的四个指定目录，共 137 个 JavaScript 文件（app 106、exploration 14、tavern 9、shared 8），以及 `tests/` 顶层 126 个非浏览器测试文件。以 [架构.md](架构.md) 第 69 行的组装原则、[开发规范.md](开发规范.md) 第 11 行的状态和资源边界为准。文件数来自逐文件语法扫描。测试扫描在补强前识别了 848 个带回调的 `test`／`it` 调用。该数字是语法清单口径。

**最高风险是世界书切换可能把旧草稿写入另一册书。** 其余优先项集中在被取消的地图操作仍提交、渲染器销毁后的异步续跑，以及来客配置替换时的状态和资源归属。下文的控制器链路来自静态追踪。测试栏的变异是用来检验断言的假设。
