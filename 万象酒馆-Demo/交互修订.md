# 当前交互修订

以你最后几轮反馈为准，旧界面描述由以下实现替代。

| 反馈                  | 已实现                                                                                                   |
| --------------------- | -------------------------------------------------------------------------------------------------------- |
| 下方主时间轴          | 保留六个大编号格，底板透明，回合名称移到顶部中央                                                         |
| 按钮与AP位置          | 清空与结算在右侧详情／手牌之间；剩余AP在左下圆环                                                         |
| 先手在第一回合左边    | 单独先手格只高亮自身；第一回合我方预览格禁用，先手结算后启用                                             |
| 时间格→角色→技能→指向 | 按阶段给可选角色或目标显示移动虚线框，选定目标才完成编排                                                 |
| 角色→技能→指向        | 同时支持；省略选时间格时自动排入最早可用的连续格                                                         |
| 角色→敌人→技能        | 点击前场角色再点击敌人，打开与拖到敌人身上相同的技能菜单；沿用目标、费用和时间格规则                     |
| 卡牌拖入时间轴        | 前场可选技能／交换，备用卡可选前场位置换入                                                               |
| 拖到其他卡牌          | 备用与前场互拖直接换人；前场到队友可选交换／队友技能；到敌人仅提供攻击／攻击技能                         |
| 敌方拖动标识          | 交叉双剑；不再显示交换AP提示                                                                             |
| 时点规则              | 明确选中的我方格优先；没选时使用最早可用格；交换始终消耗1 AP                                             |
| 卡牌与基座            | 完整三维卡可拿起，固定大石座留在地面；收拢幅度为最初调整的一半                                           |
| 场上资源条            | 六张场上卡的资源条置于石座下方，数字保留在条内；友方血量／蓝量齐全，敌方只有血量                         |
| 后场常驻信息          | 上方居中的名字；血量、蓝量与状态在鼠标悬停时显示，离开即隐藏；手机点选可查看                             |
| 敌人资源              | 只显示生命，没有蓝条                                                                                     |
| Buff预演              | 已存在层数常亮；新增层数以独立的闪烁图标显示，结算后转为常亮；清空编排即移除预测增量                     |
| 敌方意图              | 点敌方时间格或敌人，显示指向前场位置的闪烁箭头，以及该时点的预计实际伤害与Buff                           |
| 意图计算              | 使用同一份战斗预演事件，考虑换人、铁皮、虚弱及护盾；不追踪旧角色而攻击位置                               |
| 点空白取消            | 场地、时间轴间隙及面板空白均取消；先手预览也可取消                                                       |
| 清理残留              | 完成编排、结算开始、结算结束均清理意图与拖动提示；处理松手后鼠标移动的时序，防止双剑残留                 |
| 黑色卡面              | 拖动副本材质保留有效颜色对象，换人后立绘正常显示                                                         |
| 点空白取消角色        | 同时取消角色高亮、详情、时间格与目标，不保留上次角色选择                                                 |
| 右侧重叠              | 详情、结算按钮与备用卡使用独立布局区域；详情内容滚动，备用卡上方提示也留出高度                           |
| 手机横屏              | 手机以横屏布局为主；下方时间轴保持可见，详情按需展开；竖屏提示旋转，旋转后直接适配                       |
| 换人回放              | 确认结算后立即复位预演阵型，再播放实际行动；中央小条只提示回合开始／结束，中途不按阵营打断，场景始终可见 |
| 一键开关              | 双击启动会运行服务并打开游戏，重复启动复用服务；关闭仅停止本项目服务                                     |

这些改动没有修改速度、行动上限、2 AP连续格、异常结算顺序、跨战斗蓝量或Boss阶段等战斗规则。

## 时间轴与表现细化（2026-10-15）

- 修复单怪场先手与预览叠放：二者共用按实际格数计算的宽度与8px间隔，不再混用固定六格宽度，也不读取上一场的像素宽度。
- 已填行动互拖时优先交换双方起点，使用同一引擎预演校验AP、占位、敌方时间格、蓝量和换入时序；非法交换保留原计划并给出原因。拖到空格仍为移动。
- Buff外框大小沿用，内部从16×16单色剪影改为64×64多色像素绘制：力量拳头、守势金盾、虚弱断剑、易伤裂盾、再生绿叶、中毒药瓶、迟缓沙漏、流血血滴、铁皮胸甲、护盾蓝盾。层数数字、悬停说明和预计新增闪烁继续使用。
- 结算复位之后显示一次短“回合开始”，连续播放完整时间轴，不再出现我方／敌方切换通知。
- 我方增加weapon字段：格雷、绯璃用剑；时砂、塞琳、鸦隐用法杖；游隼用弓。格雷普攻命名为“剑击”，技能伤害和费用沿用。
- 敌人attackStyle分别为：苔团弹跳撞击、小蕈敲击、幼灵碎石散射、猎犬扑咬爪痕、石卫重锤、祭司余烬弹、巨像石拳、母体孢子齐射。
- 攻击预备、弹道、命中粒子及受击闪光有统一时序，结算等待对应动作时长。动画从引擎事件读取skill稳定ID，避免按中文文案判断技能。
