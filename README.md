# 万象酒馆

纯静态浏览器单机游戏，玩家自行配置兼容 Chat Completions 的 AI 接口。游戏运行不需要 Node 服务、账号或开发者的 API Key。

## 部署到 GitHub Pages

1. 将本目录上传至 GitHub 仓库，保留 `.github` 和 `万象酒馆-Demo` 的相对位置。
2. 仓库 `Settings → Pages → Source` 选择 `GitHub Actions`。
3. 推送到 `main`／`master`，或在 `Actions → Deploy game to GitHub Pages` 点击 `Run workflow`。
4. 工作流完成后，打开 Pages 提供的网址。

已提供 Netlify 与 Vercel 配置，导入此仓库即可构建。发布目录为 `万象酒馆-Demo/dist`，只上传这个目录也可托管到其他静态空间。无需配置服务器环境变量或密钥。

## 本地构建

需要 Node 22.13 或更新版本。在此目录运行 `npm run build`。开发时进入 `万象酒馆-Demo`，执行 `npm ci` 后使用原有启动器；生产发布不使用该启动器。

## 存档和接口

存档、聊天、归档、总结、世界书、导入预设、脚本偏好及立绘保存在各玩家自己的浏览器数据库。首次打开为全新进度，内置青缘供开发测试，伊蒂丝、长景月汐、潘多拉按教程与事件加入。

在“设置 → 开发者模式”页可导出／导入完整备份。备份默认不包含 API 密钥；接口设置可选择在自己的设备记住密钥。使用无痕模式、清除网站数据或更换网址前，请先导出备份。

AI 与图床直链由浏览器请求，因此相应服务需要允许跨域。图床不允许读取时，可下载图片再通过本地文件导入。正在进行的 AI 请求刷新后会中断，不自动重试；战斗刷新恢复最近的可操作回合。

发布包由白名单构建，不包含本机 `.runtime`、个人存档、导入预设、接口连接、密钥、测试产物或开发用服务。

详细开发约定、测试与架构见 `万象酒馆-Demo/开发规范.md`、`架构.md` 和 `静态化适配.md`。
